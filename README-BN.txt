ছবি যোগ:
- আপাতত placeholder.svg দেখা যাবে।
- আপনার ছবির ফাইল এখানে রাখুন।
- সবচেয়ে সহজভাবে placeholder.svg-এর জায়গায় নিজের JPG/PNG ব্যবহার করে HTML-এর src পরিবর্তন করুন।
- GitHub Pages-এ publish করার আগে phone/email/Facebook তথ্য contact.html-এ বদলান।
